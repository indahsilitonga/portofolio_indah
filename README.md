## 💻 Menjalankan Secara Lokal

```bash
# 1. Install dependensi (jika belum)
npm install

# 2. Jalankan development server
npm run dev

# 3. Build untuk produksi
npm run build

# 4. Preview hasil build produksi
npm run preview
```
